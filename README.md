# GeminiWave consulting website

Public website: https://geminiwave.com/

This buildless HTML/CSS/JavaScript site presents Faheem Faheem’s engineering consulting capabilities. GitHub Pages serves the root of the existing `main` branch; `CNAME` preserves the custom domain.

## Pages

- `index.html`: services, general career background, engagement options and project inquiry helper.
- `cases.html`: high-level experience and transferable capabilities. Existing section anchors are retained for shared links.
- `engineering-readiness-checklist.html`: general discussion checklist, not a certification or release decision.
- `privacy.html`: website and email-inquiry privacy notice.
- `apps/`: legacy static concept pages, clearly identified as nonoperational.

## Publishing rules

Publish independently written service descriptions and verified high-level career facts. Employer names identify prior experience and must not imply endorsement, current affiliation, ownership of technology or rights to license it.

Do not add internal presentations, correspondence, customer reports, prototype photographs, technical specifications, research data, proposal details, patient information or controlled technical material without documented publication clearance. A personal copy, authorship, a missing confidentiality label or a public grant reference does not establish that clearance.

Any third-party images require an appropriate license or permission. Prefer links to authoritative public sources over copying their figures. Public sources must support the exact claim being made. Generic concept illustrations must be labeled; no simulated results or product images may be presented as actual client work.

The homepage concept illustration is AI-generated and depicts general consulting themes. The analysis workflow is original HTML/CSS, with no employer models, dimensions or results. This site makes no clinical-efficacy, diagnostic-performance, regulatory-approval, funding-success or guaranteed project-outcome claim.

## Inquiry behavior

The form prepares an email locally for the visitor to review. It does not submit, store or automatically send the inquiry. Direct email remains available without JavaScript. Initial inquiries should be nonconfidential; project acceptance and technical-file exchange follow scope, conflict and confidentiality review.

## Checks

Run `node --check app.js`. Check page navigation, experience-tab keyboard controls, inquiry validation and message preparation, internal links, mobile layout and structured data. Review both rendered copy and repository files before publishing. Private working records do not belong in this repository.
